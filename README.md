# Podkop custom lists

Общие списки доменов и IP для двух роутеров с podkop (дом + дача).

## Использование

В LuCI → Podkop → настройки секции:
- **Внешние списки доменов** → raw-ссылка на `domains.txt`
- **Внешние списки подсетей** → raw-ссылка на `ips.txt`

## Community-списки

Эти сервисы уже есть в podkop — просто включите в настройках:
- `youtube` — YouTube + googlevideo
- `telegram` — домены + IP подсети
- `discord` — домены + IP подсети
- `meta` — Instagram, Facebook
- `twitter` — X/Twitter
- `google_ai` — Gemini, Bard
